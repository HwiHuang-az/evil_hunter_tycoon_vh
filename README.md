# Evil Hunter Tycoon VH

Bộ công cụ và dữ liệu tham khảo bằng tiếng Việt dành cho người chơi **Evil Hunter Tycoon**.

## Chạy trên máy

```bash
npm install
npm run serve
```

## Build bản production

```bash
npm run build
```

Bản build được xuất vào thư mục `docs` để triển khai bằng GitHub Pages.

## Bản quyền và ghi nguồn

- Bản Việt hóa và các thay đổi do **HwiHuang-az** thực hiện.
- Phát triển và Việt hóa bởi **Hwi Huang**.
- Tên game, hình ảnh và các tài sản liên quan thuộc về chủ sở hữu tương ứng. Project này không phải sản phẩm chính thức của nhà phát hành.
